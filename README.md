# Hi, I'm Jay Koladiya 👋

💎 I work in the **diamond and jewelry trade** in Surat, India, dealing in natural and lab-grown polished diamonds.

🌏 I trade with Hong Kong, China, Vietnam, Cambodia, the Philippines and Indonesia.

🛠️ I build tools that automate the daily work of the business: invoicing, stock, catalogs and pricing.

### 🏢 Work

- **Diamond ICQ**: Hong Kong–based GIA-certified diamond and jewelry wholesaler
- **Zairra Jewels Ltd**: Hong Kong natural and lab-grown diamond trading

### 🧰 Things I've built

| Project | What it does |
|---|---|
| 🧾 **Invoice & Memo Portal** | Makes invoices, memos and export invoices in USD/HKD for the Hong Kong companies |
| 📄 **Proforma Invoice Portal** | Replaces a daily Excel macro workbook so invoices can be made from a phone or PC |
| 💰 **Rap Price Calculator** | Diamond price calculator based on Rapaport pricing, for mobile and web |
| 📬 **Daily Stock Email** | Automated daily stock list sent to clients from a live CSV |
| 📚 **Catalog PDF Generator** | Python tool that turns an Excel stock list into a jewelry catalog PDF |
| 📅 **Calendar → Sheets Sync** | Google Apps Script that syncs Calendar events to a Sheets tracker |
| 🖥️ **Office Asset Portal** | Asset tracking and monthly audit, using Google Sheets as the database |
| 🛒 **Shopline Upload Tracker** | Tracks e-commerce product uploads |
